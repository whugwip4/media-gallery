# МедиаГалерея

Веб-приложение «Мультимедийная галерея». Учебный проект производственной практики ПП.05.01.

На сайте можно смотреть изображения, видео и аудио, разделенные по категориям, и искать материалы по названию. После регистрации пользователь добавляет свои материалы и видит их в личном кабинете.

## Технологии

- Next.js 16 (App Router), React 19, TypeScript
- Tailwind CSS 4, шрифты Golos Text и JetBrains Mono, оформление описано в `docs/design-system.md`
- MySQL (MariaDB из XAMPP), драйвер mysql2
- lucide-react (иконки)

## Запуск

1. Установить зависимости:
   ```
   npm install
   ```
2. Запустить MySQL в панели XAMPP (в этом проекте MySQL работает на порту 3307).
3. Скопировать `.env.example` в `.env.local` и при необходимости поменять настройки подключения.
4. Создать базу данных и таблицы (команду можно запускать повторно, данные не пропадут):
   ```
   npm run db:setup
   ```
   Тот же результат даст импорт `database/schema.sql` и `database/seed.sql` во вкладке «Импорт» в phpMyAdmin.
5. Запустить сайт и открыть http://localhost:3000:
   ```
   npm run dev
   ```

Проверить подключение к базе можно по адресу http://localhost:3000/api/health.

## Структура проекта

```
database/          SQL-скрипты: схема базы и начальные данные
docs/              описание оформления и файлы логотипа
scripts/           служебные скрипты (создание базы)
public/demo/       демонстрационные изображения
src/app/           страницы сайта (каждая папка – адрес)
src/components/    компоненты интерфейса
  auth/            формы входа и регистрации
  layout/          шапка, меню, подвал
  materials/       карточки, сетка галереи, фильтры, формы материалов
  ui/              общие элементы: заголовки, уведомления
src/lib/           типы данных, работа с данными, подключение к БД
```

## Страницы

| Адрес | Страница |
|---|---|
| `/` | Главная |
| `/gallery` | Общая галерея |
| `/images`, `/videos`, `/audio` | Разделы по типу материала |
| `/materials/[id]` | Просмотр материала |
| `/search` | Поиск по названию |
| `/register`, `/login` | Регистрация и вход |
| `/profile` | Личный кабинет |
| `/upload` | Добавление материала |
